Pipeline Architecture & Contributions

  • CUDA FP16 Acceleration: Executed YOLOv11 directly on NVIDIA Tensor Cores in half-precision, achieving stable 25–35+ FPS on live 720p/1080p video feeds.
  • Ground-Contact Perspective Geometry: Implemented 4-point polygon testing (pointPolygonTest) evaluated at the bottom-center tire patch (cx, y2), eliminating lane misclassification from elevated camera pitch angles.
  • Multi-Frame Streak Verification: Directional flow and zone intrusion rules require 4 consecutive confirmed frames before firing alerts, filtering out detector bounding box jitter.
  • Decoupled Asynchronous Persistence: Database I/O is offloaded to a background daemon with SQLite Write-Ahead Logging (WAL) and batch commits, maintaining <0.3ms disk overhead in the primary CV inference loop.
  • Interactive First-Frame Configurator: Web-based polygon region configurator enabling operators to define lanes and restricted zones dynamically without code changes.
